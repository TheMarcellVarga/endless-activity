# Brand And Media

## Purpose

Define a brand direction strong enough to guide the app icon, screenshots, portfolio case study, and visual references.

Use `brandkit` for identity and presentation boards. Use `imagegen-frontend-mobile` for native app screen references.

## Working Name

Endless Activity.

The name is literal and clear for planning. Phase 1 may explore alternatives, but implementation can proceed with this name unless a stronger option is selected.

## Brand Promise

When you are bored, the next thing to do should be one swipe away.

## Tone

Direct:
- "Try this."
- "Save it for later."
- "Too much? Lower the energy."

Light:
- mild personality
- no fake hype
- no motivational lecture

Useful:
- concrete actions
- realistic time and cost
- clear next steps

## Visual Keywords

- tactile
- quick
- optimistic
- native
- clean
- activity-led
- lightly playful
- not childish

## Avoid

- generic dating-app clone
- purple AI startup gradients
- beige lifestyle sameness
- mascot-driven identity
- overly gamified streak language
- social-media dopamine framing

## Logo Direction

Possible metaphors:
- stacked cards
- spark of action
- path branching into choices
- simple swipe motion
- calendar-free activity prompt

The logo should work as:
- iOS app icon
- small navigation mark
- portfolio/case-study mark
- monochrome mark

## App Icon Direction

Requirements:
- readable at small sizes
- not dependent on text
- strong silhouette
- compatible with iOS rounded-square mask
- no complex scene

Use `brandkit` for concept boards before finalizing.

## Screenshot Direction

Use `imagegen-frontend-mobile` or real simulator screenshots after implementation.

Screenshots should show:
- Discover card
- saved list
- preferences
- detail sheet
- empty state or reset flow if polished

## Case Study Assets

Use `brandkit` for:
- identity overview
- app icon presentation
- card system board
- portfolio case-study hero image

Use `gpt-taste` only if building a separate landing/case-study web page.
